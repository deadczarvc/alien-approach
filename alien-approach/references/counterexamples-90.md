# КОНТРПРИМЕРЫ — 90 иноземных методов (второй эшелон)

Паттерн один (кейс раскраски плоскости, анонимно): задача тупит в своём домене → мост в соседний формализм → там тривиальна → результат возвращается мостом. Мост берётся, только если в чужом домене есть готовый решатель (SKILL.md, механика мостов).

## I. Физика — система как физическое тело
1. **Термодинамический отжиг.** Внести хаос (рандомизация таймаутов/порядка), медленно охлаждать, оставляя улучшения — конфиги, которых разум не придумает.
2. **Закон сохранения дефекта.** Баг не исчезает — перетекает в другой слой (ретрай, кэш, часовой пояс). Искать, куда перетёк.
3. **Фазовый переход.** Система не «медленно деградирует» — у неё критическая точка (пул, лимит дескрипторов). Искать точку, не наклон.
4. **Резонанс.** Два безобидных периода (healthcheck 30с + cron 30с) складываются в катастрофу. Искать совпадения частот.
5. **Энтропия логов.** Рост разнообразия сообщений при той же функции = деградация дизайна. Мерить и алертить.
6. **Трение.** «Медленно» — лишняя поверхность контакта: убери вызов, скорость придёт сама.
7. **Принцип Ле Шателье.** Давление смещает равновесие куда хуже: ретраи усиливают перегрузку. Снимать нагрузку, не давить.
8. **Суперпозиция и эффект наблюдателя.** До пробы сервис «и жив, и мёртв»; проба меняет состояние (прогрев, слот). Наблюдение имеет цену.
9. **Инерция.** Большую систему не поворачивают мгновенно — разгон/торможение поэтапно. Миграция = момент, не команда.
10. **Погрешность измерения.** Единичный замер — шум; только интервалы и повторы.

## II. Биология — система как организм
11. **Иммунитет.** Не лечить каждую болезнь: канарейки + авто-карантин по сигнатуре + записанный рецепт.
12. **Эволюционный отбор конфигов.** Мутировать популяцию настроек, отбирать по метрике — поколение 30 обгонит ручной подбор.
13. **Паразитология реестра.** Каждый сервер — симбионт или паразит (ест бюджет стартов). Регулярный анализ реестра.
14. **Эпидемиология бага.** Дефект распространяется по графу зависимостей (SIR): заражённые, контакты, карантин (= revert).
15. **Гомеостаз.** Фиксировать не значения, а контуры обратной связи.
16. **Апоптоз.** Всё должно уметь умирать само: TTL на сессии, воркспейсы, локи. Без смерти = опухоль.
17. **Мимикрия.** Зрелый баг маскируется под штатный warning. Ищи «подражателей».
18. **Метаболизм.** Диагностируй потоки (вход/выход в секунду), не только состояния.
19. **Нейропластичность.** После инцидента зафиксируй новую норму как baseline, не возвращай «как было».
20. **Стволовые клетки.** Пара недифференцированных заготовок; дифференцировать только по реальной потребности.

## III. Математика — формальные мосты (ядро)
21. **Мост-перенос (дискретное→непрерывное).** «Найти баг» → «оценить меру класса отказов»; сэмплить меру, а не перебирать кейсы.
22. **Двойственность.** Не доказывать «работает» — искать минимальный контрпример (двойственная задача часто тривиальна).
23. **Инвариант.** Величина, неизменная при корректной работе (сумма, счётчик); отклонение = баг без единого теста.
24. **Редукция.** Незнакомый отказ свести к известному классу; классификатор сильнее энциклопедии фиксов.
25. **Диагональный аргумент.** Доказать существование незакрытого кейса без перебора: случай, отличающийся от каждого в своей позиции.
26. **Минимакс.** Проектировать от худшего адаптивного противника, не от среднего пользователя.
27. **PCP-сэмплинг.** Несколько случайных строк лога ловят ложь отчёта «всё зелёное» с высокой вероятностью.
28. **Информационная нижняя граница.** Сколько бит нужно для диагноза? Меньше нет — менять инструментацию, не гадать.
29. **Изоморфизм задач.** Медленный дрен = упаковка; ретраи = очередь с приоритетом. Нашёл изоморфизм — взял готовое решение.
30. **Предельные переходы.** Проверять на 0, 1, 10⁷: баги живут на границах.

## IV. Экономика — система как рынок
31. **Error budget.** Надёжность = расходуемый бюджет; исчерпан — стоп фич, только долги.
32. **Аукцион ресурсов.** Не статические квоты — торги сервисов за CPU/память в моменте.
33. **Внутренние цены.** Тариф на вызов (мс/деньги/риск) — ненужные вызовы вымрут сами.
34. **Опцион вместо плана.** Дешёвый опцион на откат (флаг, бэкап) вместо дорогого «идеального».
35. **Bank run доверия.** Ложный зелёный статус обваливает доверие; восстанавливается серией живых проб.
36. **Экстерналии.** Спам логами = издержки на всех: тарифицировать или глушить в источнике.
37. **Моральный риск.** Автор, проверяющий себя, недоусердствует: разделяй автора и приёмщика.
38. **Гиперинфляция метрик.** «Всё критично» = обесценивание. Одна скудная топ-метрика.
39. **Трансакционные издержки.** Интеграция = контракт с пожизненным TCO; считать до подключения.
40. **Хвосты.** Пользователь живёт в p99, не в среднем.

## V. Криминалистика — система как место преступления
41. **Chain of custody.** Лог = улика только с хэшем, временем, путём.
42. **Презумпция невиновности.** Модуль не виноват без изолированного воспроизведения.
43. **Перекрёстный допрос.** Каждый фикс атакует независимая сторона (адверсариальная волна).
44. **Почерк.** У компонентов отпечаток (формат ошибок, тайминги) — автор падения опознаётся и без логов.
45. **Алиби.** Дешевле доказать, где компонент НЕ мог быть, чем где был.
46. **Мотив.** Кому выгоден баг? Если сбой снимает нагрузку — ищи механизм самозащиты.
47. **Очная ставка.** Столкни два лога одного события: расхождение = дыра в наблюдаемости.
48. **Реконструкция по косвенным.** Таймлайн из mtime, TTL-остатков, счётчиков. Нет логов ≠ нет событий.
49. **Презумпция испорченности кэша.** Любой факт из памяти/кэша под подозрением до свежей пробы.
50. **Вердикт с оговоркой.** Уровень уверенности обязателен: verified / unverified / требует проверки.

## VI. Лингвистика и археология — система как текст
51. **Диалекты ошибок.** Словарь диалектов слоёв → маршрутизация по одной фразе.
52. **Ложные друзья переводчика.** «session» в разных системах = разное; межсистемный глоссарий.
53. **Стратиграфия.** Нижние слои не зависят от верхних; инверсия = архитектурный дефект.
54. **Розеттский камень.** Один запрос с логами всех слоёв — эталон для калибровки наблюдаемости.
55. **Палеография.** Три частичных лога одного события читаются как один целый.
56. **Этимология конфига.** Поле без происхождения (git-blame) = мина.
57. **Мёртвые языки.** Читаемые, но неисполняемые ключи: каталогизировать и хоронить.
58. **Дескриптивизм.** Описать, как реально называется в коде; выровнять доку с фактом.
59. **Перевод с потерями.** Каждая прослойка (JSON→YAML→env) теряет смысл; round-trip тест меряет потери.
60. **Палимпсест.** Под свежим патчем проступает старая логика; читай историю файла.

## VII. Химия — система как вещество
61. **Катализатор.** Не участвовать в реакции: однострочный хук делает починку самопроизвольной.
62. **Ингибитор.** Анти-паттерн = катализатор класса багов; один guard в общем месте гасит класс.
63. **Точка росы.** Скрытые проблемы конденсируются при охлаждении нагрузки: тестируй в idle.
64. **Легирование.** 2% разнородного (формалка к фаззингу) прочнее любого чистого метода.
65. **Усталость металла.** Убивают циклы (реконнекты, рестарты), а не пики.
66. **Коррозия границы сред.** Разрушение на стыках код↔конфиг↔env; защищай границу, не крась середину.
67. **Полиморфизм.** Один конфиг = три фазы (dev/test/prod); фазу фиксировать явно.
68. **Титрование.** Нагрузку по капле до изменения цвета — точный порог.
69. **Сверхпроводимость.** Убери сопротивление (boilerplate) из критического пути — станет мгновенно.
70. **Хиральность.** Зеркальная конфигурация — не та же молекула; тестируй зеркало.

## VIII. Экология и геология — система как среда
71. **Пищевая цепь.** Падение хищника (сторожа) → взрыв популяции сирот. Мониторь трофические уровни.
72. **Инвазивный вид.** Чужой процесс без хищников размножается: лимиты + reaper.
73. **Сукцессия.** После пожара (рефактора) — стадии зарастания; управляй стадиями.
74. **Ключевой вид (keystone).** Крошечный хук держит экосистему: страхуй сильнее «больших».
75. **Каротаж.** Датчики по глубине стека без вскрытия (остановки).
76. **Тектоника.** Напряжение копится на границах интерфейсов; инцидент = разряд дрейфа.
77. **Радиоуглеродный анализ.** Возраст по изотопам (mtime, sha), не по ярлыку «свежий».
78. **Озоновая дыра.** Кризисы находят, ища другое: журнал странных наблюдений обязателен.
79. **Островная биогеография.** Изолированный сервис гниёт; коридоры миграции обязательны.
80. **Вулканическая тишина.** Полная тишина логов активной системы = предвестник, не здоровье.

## IX. Игры и метаметоды
81. **Шахматная ретроспектива.** Потеря не в последнем ходе, а в раннем тихом решении.
82. **Один решающий удар.** Вместо десяти косметических фиксов — единственный корневой.
83. **Джазовая сетка.** Импровизация только на известной сетке инвариантов.
84. **Ставка на незаканчивающийся маршрут.** Не «быстрее всех», а «единственный, кто не сойдёт».
85. **Флексагон.** Пересложи систему иначе — та же поверхность откроет скрытые состояния.
86. **Коллаж.** Собери из проверенных фрагментов (stdlib, хелперы); оригинальность в сборке.
87. **Пуантилизм.** Отойди: агрегат недельного лога видит болезнь, невидимую в суточном.
88. **Контрапункт.** Positive- и negative-контроли всегда парой — слышнее любого соло-теста.
89. **Негативное пространство.** Проектируй, что система НЕ делает: списки запретов надёжнее списков действий.
90. **Смена партитуры (мета-мост).** Не решается в своём ключе — перепиши в соседнем формализме и реши там. Не сильнее бей — смени игру.

## X. Формальный мост — инвариант как вход решателя (живые рантаймы)

- **F0a SMT (z3 + sympy; `pip install z3-solver sympy`).** Инвариант → предикаты z3; `sat` с моделью = кандидат решения; `unsat`-ядро = диагноз (класс решений пуст). Правило кодировки: модель не сравнивается дословно — проверяется выполнение предикатов.
- **F0b Prolog (SWI-Prolog `swipl`).** Инвариант → Хорн-логика; запрос-истина печатает маркер (positive); запрос-ложь обязан дать rc≠0 (negative). На Windows после установки `swipl` бывает вне PATH — `probe-f0.py` ищет и канонический путь установки.
- **F0c ASP (clingo; `pip install clingo`).** Пространство конфигураций → логическая программа; answer set = допустимая конфигурация; UNSAT = перенос противоречия (класс решений пуст).
- **Правило моста:** нет кодировки инварианта в решателе — нет моста F0, только метафора. Runnable-контроль: `scripts/probe-f0.py` (pos+neg по каждому решателю, PASS/FAIL/SKIP построчно).
