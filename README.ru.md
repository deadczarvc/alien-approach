# alien-approach — скилл «Иноземный Подход»

[English](README.md) · **Русский**

Скилл для агента. Он нужен, когда задача не решается в своём домене. Агент не давит сильнее
тем же методом. Он строит **мост** в соседний формализм, где уже есть готовый решатель.
Там задача решается, результат переводится обратно, а живая проба исходного симптома
подтверждает итог.

> Не бить сильнее — сменить игру.

Версия **0.9.0** · MIT · работает с любым агентом, который читает `SKILL.md` (Claude Code,
Claude.ai, агенты типа Codex и подобные).

## Когда применять

Достаточно одного признака:

- две и более честные попытки в домене задачи ничего не сдвинули;
- перебор растёт быстрее ресурсов;
- идеи ходят по кругу вокруг одного метода;
- сами термины задачи её ограничивают.

Для тривиальных багов скилл **не** применяют. Сначала агент проходит лестницу из 30 обычных
методов. Мост — второй эшелон.

## Как работает

| Фаза | Якорь | Что происходит |
|---|---|---|
| 1 | 诊断 застревание | Записать в журнал, что пробовали и почему не вышло; пройти обычную лестницу |
| 2 | 搜索 выбор моста | Взять 2–3 моста из каталога; мост годен, только если там есть готовый решатель |
| 3 | 转换 перенос | Переформулировать задачу в терминах моста; назвать инвариант |
| 4 | 治疗 решение там | Применить чужой решатель (теорема, механизм, кодировка в SMT, Prolog или ASP) |
| 5 | 测试 возврат | Перевести результат обратно, выполнить живую пробу, перепроверить инвариант |

Классы мостов: **M** — перенос метода (мера вместо перебора), **S** — перенос утверждения
(инвариант), **C** — перенос противоречия (класс решений пуст), **P** — цена вместо запрета,
**X** — формальный мост (инвариант → z3, SWI-Prolog или clingo).

Вывод агента всегда содержит пять полей: `bridge`, `invariant`, `proof`, `verdict`, `journal`.

## Состав

```text
alien-approach/
├── SKILL.md                         сам скилл (текст по-русски, термины по-английски)
├── references/
│   ├── examples-30.md               L1: 30 обычных методов (пример корпуса — MCP-серверы и сервисы)
│   ├── counterexamples-90.md        L2: 90 мостов из 9 доменов + формальный класс X
│   └── alien-approach.xtml          та же логика XTML-документом для обмена между агентами
└── scripts/
    └── probe-f0.py                  проверка решателей для моста X
```

## Установка

Скачайте последний релиз со страницы
[Releases](https://github.com/deadczarvc/alien-approach/releases):

- `alien-approach-<версия>.skill` — загрузите в Claude.ai (Settings → Capabilities → Skills)
  или установите любым инструментом, который принимает пакеты `.skill`;
- `alien-approach-<версия>.zip` — распакуйте в папку скиллов, например `~/.claude/skills/`
  для Claude Code; должен получиться путь `~/.claude/skills/alien-approach/SKILL.md`.

Сверьте скачанный файл с `SHA256SUMS` из того же релиза.

Решатели для моста X — по желанию:

```bash
pip install z3-solver clingo
```

SWI-Prolog установите с swi-prolog.org. Затем проверьте рантайм:

```bash
python alien-approach/scripts/probe-f0.py
```

Код 0 — хотя бы один решатель прошёл позитивный и негативный контроль; 1 — решатель дал
неверный ответ; 2 — решателей нет. Отсутствующий решатель помечается `SKIP`.

## Собрать релиз самому

```bash
python tools/build_release.py
```

Скрипт сверяет заголовок `SKILL.md` с официальными правилами скиллов, сверяет `VERSION`
с `metadata.version` и пишет в `dist/` воспроизводимые `.skill`, `.zip` и `SHA256SUMS`.
Тег `vX.Y.Z` запускает ту же сборку в GitHub Actions и публикует релиз.

## Какими методиками причёсан скилл

Структура промпта MK2, таблицы кодов CompactPrompt, логическая нотация MetaGlyph
(`∀ ⇒ ¬ ∈ ∧ ∨`), устойчивые китайские якоря фаз и копия в формате XTML. Якоря — метки фаз,
а не шифр; обещания ограничены тем, что измерено.
